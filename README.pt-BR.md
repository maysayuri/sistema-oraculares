## ✦ Visão Geral

**Sistemas Oraculares** não é uma aplicação de tarot genérica.  
É uma plataforma oracular especializada, construída sobre conhecimento autêntico das tradições de Umbanda, Esquerda e do Tarot Rider-Waite - onde cada sistema possui identidade própria, estrutura de leitura independente e conteúdo desenvolvido para uso profissional.

A aplicação funciona como uma **SPA de arquivo único sem dependências**, sem etapa de build e sem necessidade de backend. Todo o conteúdo está embutido inline e opera completamente offline.

A partir da v8.0, a interface é **totalmente otimizada para desktop** por meio de um sistema de layout adaptativo responsivo, preservando integralmente a experiência mobile estabelecida desde a v1.0.

## ✦ Sistema Duplo de Leitura

Cada um dos três sistemas de entidade integra **dois baralhos distintos**:

**1. Baralho Específico** (36 cartas autorais) - o oráculo próprio da entidade  
**2. Baralho de Naipes** (52 cartas) - baralho comum como substituto funcional

A plataforma especifica quais cartas retirar do baralho de 52 antes de cada sessão,  
já que cada sistema utiliza um subconjunto distinto de 36 cartas.

## ✦ Consulta Interativa - O Jogo

Simulação de tiragem completamente funcional com todas as 78 cartas do Rider-Waite.

**Fluxo da sessão:**
1. Selecionar a quantidade de cartas: 1, 3, 5, 7, 10 ou 13
2. Pressionar **EMBARALHAR** - animação de embaralhamento iniciada
3. Pressionar **STOP** - carta selecionada pela intuição naquele momento
4. Repetir até completar a tiragem
5. Revelar cada carta individualmente para acessar a leitura completa
6. Pressionar **LEITURA GERAL** - análise automatizada gerada

**Análise Completa inclui:**
- Badges: quantidade de Arcanos Maiores, naipe predominante, cartas invertidas
- Por carta: ilustração · posição · significado · LUZ/SOMBRA · PPF · conselho
- **Síntese Final** - interpretação integrada da tiragem completa
- **Conselho Lúcido** - orientações concretas derivadas das cartas reveladas

**Interpretação de Cartas Invertidas:**  
Modelo não-determinista - quatro perspectivas: bloqueio · interiorização · excesso · ajuste.

| Quantidade | Tiragem | Finalidade |
|---|---|---|
| 1 | Consulta Direta | Resposta objetiva |
| 3 | Passado · Presente · Futuro | Linha do tempo |
| 5 | Cruz Simplificada | Leitura cruzada |
| 7 | Tiragem das Influências | Panorama completo |
| 10 | Cruz Celta Completa | Leitura profissional |

## ✦ Layout Responsivo - v8.0

A interface utiliza um **sistema adaptativo de três breakpoints** que preserva o comportamento mobile  
enquanto entrega uma experiência de desktop completamente profissional.

| Breakpoint | Dispositivo | Layout |
|---|---|---|
| Padrão | Mobile (< 768px) | Coluna única, largura total - layout original |
| `≥ 768px` | Tablet paisagem | Grid de 2 colunas no portal, grids maiores |
| `≥ 1024px` | Desktop | CSS Grid multicolunas, nav sticky, hover |
| `≥ 1600px` | Telas grandes | max-width estendido, grids maiores |

**Funcionalidades desktop (≥ 1024px):**
- CSS Grid multicolunas: navegação / cartas / painel de análise
- Nav de abas (`eb-nav`) sticky com `backdrop-filter` blur ao rolar
- Botão voltar (`btn-voltar`) fixo no viewport
- Hover em todos os tipos de carta: escala + sombra suave
- Grids de cartas fluidos via `repeat(auto-fill, minmax())`
- Conteúdo limitado a `max-width: 1400px` (1500px em ≥ 1600px)
- Scrollbar customizada com cor da identidade visual
- Tipografia fluida com `clamp()`
- Modal: 2 colunas para LUZ/SOMBRA, 3 colunas para PPF

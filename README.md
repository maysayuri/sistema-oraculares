## ✦ Overview

**Sistemas Oraculares** is not a generic tarot application.  
It is a specialized oracular platform built on authentic knowledge of Umbanda, Esquerda, and Rider-Waite traditions - where each system carries its own identity, independent reading structure, and content developed for professional use.

The application runs as a **zero-dependency single-file SPA** with no build step and no backend requirement. All content is embedded inline and functions fully offline.

As of v8.0, the interface is **fully optimized for desktop** through a responsive adaptive layout system, while preserving the complete mobile experience established from v1.0.

## ✦ Dual Reading System

Each of the three entity systems integrates **two distinct decks**:

**1. Proprietary Deck** (36 authored cards) - the entity's own oracle  
**2. Playing Card Deck** (52 cards) - standard deck as a functional substitute

The platform specifies which cards to remove from the 52-card deck before each session,  
since each entity system draws from a distinct 36-card subset.

## ✦ Interactive Consultation - The Game

A fully functional card draw simulation operating on all 78 Rider-Waite cards.

**Session flow:**
1. Select card count: 1, 3, 5, 7, 10, or 13
2. Press **EMBARALHAR** - shuffle animation initiates
3. Press **STOP** - card selected by intuition at that moment
4. Repeat until the spread is complete
5. Reveal each card to access its full reading
6. Press **LEITURA GERAL** - automated full reading analysis is generated

**Full Reading Analysis includes:**
- Context badges: Major Arcana count, dominant suit, inverted card count
- Per card: illustration · position · meaning · LUZ/SOMBRA · Past/Present/Tendency · counsel
- **Síntese Final** - integrated interpretation of the complete spread
- **Conselho Lúcido** - concrete, action-oriented guidance derived from the revealed cards

**Inverted Card Model:**  
Non-deterministic. Four analytical perspectives: blockage · internalization · excess · necessary adjustment.

| Count | Spread | Purpose |
|---|---|---|
| 1 | Direct Consultation | Single focused response |
| 3 | Past · Present · Future | Temporal timeline |
| 5 | Simplified Celtic Cross | Cross-referenced reading |
| 7 | Spread of Influences | Panoramic overview |
| 10 | Full Celtic Cross | Professional-level reading |
| 13 | The Full Year | One card per month |

## ✦ Responsive Layout - v8.0

The interface uses a **three-breakpoint adaptive system** that preserves mobile behavior  
while delivering a fully professional desktop experience.

| Breakpoint | Target | Layout |
|---|---|---|
| Default | Mobile (< 768px) | Single column, full-width - original layout |
| `≥ 768px` | Tablet landscape | 2-column portal grid, wider card grids |
| `≥ 1024px` | Desktop | Multi-column CSS Grid, sticky nav, hover states |
| `≥ 1600px` | Large screens | Extended max-width, larger card grids |

**Desktop features (≥ 1024px):**
- Multi-column CSS Grid layout: navigation / cards / analysis panel
- Tab navigation (`eb-nav`) sticky with `backdrop-filter` blur on scroll
- Back button (`btn-voltar`) fixed in the viewport
- Hover interactions on all card types: scale + drop shadow
- Card grids scale via `repeat(auto-fill, minmax())` - fluid column count
- Content `max-width` capped at 1400px (1500px at ≥ 1600px)
- Custom scrollbar with brand-colored thumb
- Fluid typography via `clamp()`
- Modal: 2-column LUZ/SOMBRA, 3-column Past/Present/Future
